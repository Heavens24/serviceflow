# ServiceFlow

## 🚀 Overview

ServiceFlow is a modern appointment booking and business management platform for service-based businesses.

Examples include:

- Electricians
- Mechanics
- Welders
- Doctors
- Dentists
- Hair Salons
- Tutors
- Personal Trainers
- Plumbers
- Optometrists
- And many more.
